  own words: `test_the_same_prompt_twice_is_zero_model_calls_the_second_time`
  drives `/v1/spec` twice through a counting transport and asserts one call. That
  is the only test that would catch a refiner wired in *front* of the cache.
- **The design, which is the part worth re-reading: every value the refiner
  proposes carries a verbatim quote from the prompt, and a value whose quote is
  not in the prompt is dropped.** An LLM asked to complete a Spec will complete
  it — confidently, from nothing — which is the exact failure the extractor's
  precision-first rules avoid. Requiring the model to point at the words turns
  "did it invent this?" into a substring test, and `merge()` runs that test on
  every field. Quoting is insensitive to case and line wrapping (the golden
  prompt wraps mid-sentence) and has a 4-character floor, because "an" is a
  substring of nearly every prompt and would make the check decorative.
- **Three further guarantees, all enforced in `merge()` rather than in the
  prompt** — prompt text is a request, code is a constraint: the deterministic
  draft always wins (the refiner fills `None`/empty, never overwrites a rule's
  value); the refiner never receives an artifact (`refine(prompt, draft)` has no
  parameter for one, asserted by signature *and* by checking the rendered prompt
  for "bpmn"); and every drop is recorded, because a silent drop during a corpus
  run is indistinguishable from a refiner that never ran. `source` becomes
  `"merged"` only if something was actually applied.
- **`cache_version(EXTRACTOR_VERSION, refiner)`** — the cache key covers the
  refiner's identity, not just the extractor's. Test: extract with no refiner,
  wire one, and the next request must recompute rather than serve the thinner
  spec. Without this, the first corpus run after switching refiners quietly
  serves specs from the pipeline you just replaced.
- **`AnthropicTransport`** — `claude-opus-5`, structured outputs constrained to
  `residue_schema()` (so a malformed proposal is not a failure mode the merge has
  to handle), `effort: "low"` since filling gaps against a quoted source is not a
  reasoning task and the corpus runs 40 times. SDK imported lazily: the service
  starts and all tests pass with neither `anthropic` nor `ANTHROPIC_API_KEY`

**Decisions I made:**
- **The refiner is OFF by default** (`WFEVAL_SPEC_REFINER=llm` opts in). There is

  partially applied rewiring is an ordering nobody proposed. This bit immediately:
  my own first test was cyclic (a step added `after: s2` while `s2` was rewired to
